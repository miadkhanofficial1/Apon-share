# Apon

> **Tagline:** Instant. Private. Yours.

A cross-platform local peer-to-peer file sharing application connecting Windows, macOS, Linux, and Android devices directly without relying on external servers or cloud intermediaries.

## Monorepo Layout

- `web/`: The official landing page built with React, Vite, and Tailwind CSS.
- `app/`: Placeholder for the upcoming desktop and mobile client powered by Tauri v2.
- `Branding/`: Master brand assets and artwork.

## Getting Started with Web

```bash
cd web
npm install
npm run dev
```
